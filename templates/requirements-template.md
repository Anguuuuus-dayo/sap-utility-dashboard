# シナリオ
電力会社のダッシュボード — 日本の大手電力会社向け発電所稼働・パフォーマンス統合管理

ターゲット：東京電力・関西電力・中部電力など大手電力会社の発電部門運用担当者・経営層

# 1. 各発電所の稼働率

## KPI カード（トップ行）
- 全発電所の総合稼働率（当日・当月・当年）
- 計画稼働率 vs 実績稼働率（達成率 %）
- 非計画停止件数（直近30日）
- 総発電量 MWh（当日累計）

## 発電所一覧テーブル
| カラム | 内容 |
|--------|------|
| 発電所名 | クリックで詳細ドリルダウン |
| 所在地 | 地域（北海道・東北・関東・中部・関西・中国・四国・九州・沖縄） |
| 発電方式 | 火力 / 原子力 / 水力 / 太陽光 / 風力 |
| 認可出力 MW | 設備容量 |
| 現在出力 MW | リアルタイム発電量 |
| 稼働率 % | ゲージ付きスパークライン |
| ステータス | 稼働中 / 定期検査中 / 緊急停止 / 調整運転 |
| 次回計画停止 | 日付・期間 |

## 稼働率ヒートマップ
- X軸：発電所、Y軸：月次（過去12ヶ月）
- セルの色：稼働率高（緑）→ 低（赤）
- 計画停止期間はグレーで区別

## 地図ビュー（GISマップ）
- 日本地図上に発電所をピンで表示
- ピン色：稼働状況（稼働中=緑、停止=赤、点検中=黄）
- ピンサイズ：発電容量に比例
- クラスタリング：同一エリアの発電所をグループ化
- ホバー：発電所名・現在出力・稼働率をポップアップ表示

# 2. 発電方式ごとのまとめ

## 発電ミックス構成（リアルタイム）
- ドーナツチャート：現時点の発電方式別発電量比率
  - 火力（LNG・石炭・石油・バイオマス別）
  - 原子力
  - 水力（ダム式・流れ込み式・揚水）
  - 再生可能エネルギー（太陽光・風力・地熱・潮力）
- 前日比・前週比・前年同期比の矢印インジケーター

## 発電方式別パネル（タブ切替）

### 火力発電
- 燃料種別出力推移（積み上げ面グラフ、24時間・7日・30日）
- 熱効率トレンド（発電方式別：CCGT / USC / IGCC）
- 起動・停止回数（デイリー）
- 燃料消費量と単価連動コストグラフ

### 原子力発電（規制対応強化）
- 原子炉ごとの出力・稼働状況
- 再稼働審査状況（原子力規制委員会審査フェーズ）
- 安全パラメータ：炉心温度・圧力・冷却水流量
- 法定検査スケジュールタイムライン

### 水力発電
- 貯水池水位（現在値・警戒水位・制限水位）
- 降水量予報連動の発電量予測
- 揚水運転モード：ポンプアップ vs 発電切替状況

### 再生可能エネルギー
- 日射量・風速のリアルタイムセンサー連動
- 太陽光・風力の予測精度トラッキング（AI予測値 vs 実績）
- 出力変動によるバッファ・蓄電池の充放電状況
- FIT/FIP収益試算

## 発電方式別CO₂排出量
- 排出係数（kg-CO₂/kWh）推移グラフ
- カーボンニュートラル目標 2050 に対する進捗ゲージ
- 排出量クレジット（J-クレジット）残高表示

# 4. 発電方式ごとの発電効率の違いを考慮した発電所の稼働最適化

## 経済負荷配分（ELD）最適化パネル
- 需要予測曲線（翌24時間・48時間）vs 現在の発電計画
- 発電コスト最小化の推奨起動・停止スケジュール
- 変更前後のコスト比較（円）・CO₂比較（t-CO₂）

## 発電効率インジケーター
| 指標 | 単位 | 説明 |
|------|------|------|
| 熱効率 | % | 燃料投入エネルギーに対する発電量比率 |
| 設備利用率 | % | 認可出力に対する実績発電量 |
| 可用率 | % | 計画停止を除いた稼働可能率 |
| 強制停止率 | % | 非計画停止による損失率 |
| ランプレート | MW/min | 出力変化速度（系統調整能力） |

## AI需要予測連携
- 気象データ（気温・湿度・日射量）×電力需要の相関モデル
- 工場・商業施設の大口需要家データとの連携予測
- 季節要因・祝日補正済み7日間需要予測グラフ
- 予測誤差アラート（±3%超過で通知）

## ユニットコミットメント最適化
- 発電機起動コスト・最小運転時間・最小停止時間を考慮
- 揚水発電の充放電タイミング最適化
- 蓄電池のSOC（充電率）管理と放電スケジュール

## 最適化シミュレーター（What-if 分析）
- 燃料価格変動シナリオ（±10〜50%）入力
- 特定発電機の計画外停止シナリオ
- 需要急増・急減シナリオ
- 結果：コスト・CO₂・需給バランスへの影響をリアルタイム試算

# 5. 各プラントのメンテナンスコストの推移

## コストサマリーKPI
- 当年度メンテナンス費用累計（予算 vs 実績）
- 発電量あたりメンテナンスコスト（円/MWh）トレンド
- 計画メンテナンス費 vs 非計画（緊急）修繕費の比率
- 機器寿命延伸投資の ROI 試算

## コスト推移グラフ
- 発電所別月次メンテナンスコスト（過去3年・積み上げ棒グラフ）
- 設備種別内訳（タービン / ボイラー / 変圧器 / 制御システム / 土木）
- 前年同月比の増減率インジケーター

## 計画停止・メンテナンスタイムライン（ガントチャート）
- 全発電所の定期検査・定期点検スケジュール
- 法定検査（電気事業法・原子炉等規制法）の期限管理
- 検査ステータス：計画 / 進行中 / 完了 / 延期
- 複数発電所の同時停止リスクアラート（需給への影響）

## 予防保全 (PdM) パネル
- IoTセンサーデータ連動：振動・温度・圧力の異常スコア
- 機器ごとの残余寿命予測（AI診断）
- 交換推奨パーツリスト・調達リードタイム
- 故障予兆アラート（スコア閾値超過で担当者通知）

## 資産管理台帳リンク
- 設備ID・型番・導入年月・累積稼働時間
- 修繕履歴ログ（作業内容・費用・担当業者）
- 次回法定検査日カウントダウン

# 8. 今回実装するスコープ

> 上記は広範な業務ビジョン。今回のダッシュボードでは `/utility-dashboard` の手札
> （KPIカード/donut/line/bar/stacked_bar/heatmap/map）で作れる範囲に絞って実装する。

- **KPIカード**: 全発電所の総合稼働率（当月） / 計画比達成率 / 非計画停止件数（直近30日） / 総発電量（当月累計）
- **donut**: 発電方式別の発電量構成比
- **line**: 月次の総合稼働率 推移
- **bar**: 発電所別 メンテナンスコスト（上位5）
- **stacked_bar**: 設備種別別の月次メンテナンスコスト（積み上げ）
- **heatmap**: 発電所 × 月 の稼働率
- **map**: 全国の発電所マップ（稼働状況ピン）
